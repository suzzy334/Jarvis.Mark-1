MAJOR PROJECT — ECE IV B.TECH PHASE-I SENTINELKEY

SentinelKey — A PUF Based Hardware Authentication Token for Universal Web Application Security

SentinelKey eliminates password phishing, credential replay, and OTP interception attacks using an SRAM Physically Unclonable Function (SRAM-PUF) inside an ESP32 microcontroller. Key material is dynamically extracted from microscopic silicon gate threshold variations and never stored on flash storage.
